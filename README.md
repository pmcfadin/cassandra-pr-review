# cassandra-pr-review

Reviews pull requests against [apache/cassandra](https://github.com/apache/cassandra) and produces a
single self-contained HTML report. The report tells a contributor whether their patch is ready to
merge, judged against the project's contribution standards, its testing regime, and general code
quality.

Development is spec-driven with [OpenSpec](https://github.com/Fission-AI/OpenSpec). Specs live in
`openspec/specs/`; proposed changes live in `openspec/changes/`. Background research is in
`docs/research/`.
